# PowerBankMenu 1.2.1 (18)

## Changes

- Reorganize General and Account settings with aligned fields, clear labels, and Japanese/English helper text.
- Prevent duplicate account saves, show progress, and restore controls and input focus after errors.
- Make device names, battery level, input/output power, low battery, and missing readings easier to scan in the native menu.
- Use an adaptive menu bar symbol, standard Settings/Close/Quit shortcuts, and a normally layered About window.
- Show full connection errors in a native detail alert.

The previous GitHub release was 1.0.13 under the SolixMenu name. This release also includes the subsequent PowerBankMenu rename, credential-persistence fixes, and macOS 27 compatibility changes already on main.

## Validation and distribution

- Marketing version 1.2.1; build 18. Deployment target remains macOS 26.0.
- Xcode 27.0 (27A266a), macOS 27 SDK; Release archive and Developer ID export succeeded.
- Export contains arm64 and x86_64 slices. Runtime UI checks were performed on Apple Silicon only.
- Strict signature verification passed with hardened runtime, sandbox, network-client, and the existing keychain access group; no debug get-task-allow entitlement.
- Japanese/light and English/dark settings and isolated save/error/keyboard flows were checked. See [GUI verification](../ui-review/2026-09-21-hig.md) for coverage and limitations.
- No real-account authentication or spoken VoiceOver test was performed.
